# exeファイルのGitHub Releases自動配布

flapping_penguinを自分・身内など少人数に配布する手段として、GitHub ActionsでビルドしGitHub Releasesに自動公開する仕組みを導入する。`vX.Y.Z` タグのpushをトリガーに、Inno Setupでビルドしたインストーラー(`setup.exe`、`%LocalAppData%` へのユーザー単位インストール)をビルド成功と同時に自動公開する。コード署名は行わず、SmartScreen警告は許容する。バージョン番号はタグの値からビルド時に自動で埋め込み、`AssemblyInfo.cs` の手動編集は廃止する。

## Considered Options

- **アプリ内自動アップデート**: 起動時の更新チェック・適用まで含める案は、更新チェック処理や再起動制御などの実装コストが少人数配布の規模に見合わないため見送った。CIによるビルド・公開の自動化のみに留める。
- **WiX Toolset**: MSIベースで本格的だが、GUIDやコンポーネント管理など学習コストが高く、この規模のアプリには過剰と判断しInno Setupを採用した。
- **コード署名証明書の取得**: 商用証明書は年間コストが配布規模に見合わず、自己署名はSmartScreenの信頼度向上にほぼ寄与しないため見送った。
- **Program Filesへのマシン単位インストール**: 管理者権限とUACプロンプトが必要になり、身内配布の手軽さを損なうため、`%LocalAppData%` へのユーザー単位インストールを選んだ。
- **Releaseの下書き(Draft)公開**: ビルド後に手動確認してから公開する案もあったが、他の判断(署名なし・タグ手動作成・リリースノート自動生成)と方向性を揃え、ビルド成功と同時に自動公開する運用とした。
